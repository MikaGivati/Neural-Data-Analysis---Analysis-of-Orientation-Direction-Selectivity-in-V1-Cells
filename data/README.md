# Data

`SpikesX10U12D.npy` — simultaneous extracellular recordings from 10 V1 units in
response to 12 directions of a moving oriented grating (200 repetitions each, ~2.9MB).
Stored as a `(10, 12, 200)` object array where each entry holds the spike times (in
seconds) for that unit/direction/repetition.

Provided as part of a Neural Data Analysis course assignment and included here for
reproducibility.
